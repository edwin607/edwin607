# Hi, I'm Edwin

I build agent systems, and I spend most of my thinking on one problem: how a machine might come to hold human values — not as rules handed down from a lab, but as meaning understood in context.

That work lives under the name **interpretive alignment**. It translates methods from sociology and design — verstehen, the sociological imagination, speculative design, participatory design — into alignment practice for LLM agents. Interpretive training data instead of bare preference pairs. A structural-reasoning evaluation called the Mills Test. Community-authored constitutions injected where agents are actually spawned, not just discussed.

### Building now

- **[interpretive-alignment](https://github.com/edwin607/interpretive-alignment)** — the research program and open toolkit: framework, charter-supervisor reference implementation, deliberation-trace dataset schema, evals.

### Shipped

- **[Field Notes of a Revolution](https://edwin607.github.io/tech-revolutionaries/)** — a web experiment treating the handwritten notebook as an artifact of technological resistance. Self-drawing vectors, margin notes, mid-sentence cross-outs. Critical design as method.
- **[ModelArena](https://github.com/edwin607/model-arena)** — a PWA for side-by-side LLM testing on OpenRouter: parallel streaming, real cost from actual token counts, persistent eval stats. [Try it live](https://edwin607.github.io/model-arena/).

### How I work

Fine-tuning when the question is about disposition, architecture when the question is about obedience, and ethnography when the question is about whose values we're talking about. LangGraph for orchestration, small models where they protect margins, frontier models where reasoning matters.
